# 리뷰

Claude가 명세별로 남기는 리뷰 기록이다. 파일 이름은 명세와 같다(`Docs/Specs/<이름>.md` → `Docs/Reviews/<이름>.md`). 규칙은 [AGENTS.md](../../AGENTS.md)의 "작업 방식".

## 틀

```markdown
# <명세 이름> 리뷰

## 1회차 — YYYY-MM-DD, `<커밋>`

재현: 빌드 <결과>, `CXMR.` <통과>/<전체>.

### R1-1 <한 줄 요약> — 열림
- 문제: 파일:줄, 발생 조건, 영향. (반드시 해결)
- 제안: 접근 방법, 쓸 API의 소스 경로:줄, 주의점. (권장 — 다르게 하면 보고 ③에 이유)
- 확인할 시험: 새로 넣거나 고칠 자동화 시험.
- 스케치: (정확한 형태가 중요할 때만, 참고용 의사코드)

## 질문
Codex가 막혔을 때 여기에 쓰고 멈춘다. Claude가 답하거나 명세를 고친다.
```

상태는 `열림` 또는 `반영함 (<커밋>)`. Codex가 반영하면 `반영함 (<커밋 제목>)`으로 바꾸고, Claude가 다음 회차에 해시로 바꾼다.
