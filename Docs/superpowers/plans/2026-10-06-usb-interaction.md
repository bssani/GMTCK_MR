# USB 상호작용 수정 계획

기존 배치/차량 로드 수정은 보존하며 현재 체크아웃에서 진행한다.

1. USB 주변을 지우는 패스, 전용 머티리얼, 스텐실과 설정 변경을 제거한다.
2. 실제 USB 메시의 재질과 변환을 유지한다. 기본 피드백은 실제 포트 크기 테두리와 공간 음향으로 제한한다.
3. 근접 상태, 정렬 대기, 추적 손실 유예와 인접 포트 전환을 구현한다.
4. 메시 보존, 근접 반응, 정렬 대기, 추적 손실, 오래된 자세와 포트 전환 자동화 테스트를 수행한다.
5. Editor 빌드와 CXMR 전체 자동화 테스트를 실행한다. 합성 테스트 결과와 헤드셋에서 확인하지 않은 가시성/음향을 구분해서 보고한다.

가림 문제는 현장 깊이 데이터를 확인해야 한다. 포트 주변 삭제나 투명화를 대안으로 적용하지 않는다.
