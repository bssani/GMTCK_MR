# 실물 케이블 USB 상호작용

실제 차량에 USB를 꽂는 느낌을 우선한다. 차량 표면과 USB 형상을 유지하며 주변 콘솔을 지우거나 투명하게 만드는 처리는 사용하지 않는다.

- 실제 USB 메시의 재질, 위치와 크기를 피드백 중에도 유지한다.
- 포트 크기의 테두리로 접근/근접/정렬을 표현한다. 기본 설정은 긴 안내 빔과 확대 효과를 사용하지 않는다.
- 가장 가까운 포트만 반응하며 방향이 틀려도 4cm 이내에서는 근접 반응을 준다.
- 손 추적이 0.15초 이내로 끊기면 기존 표시를 잠깐 유지한다. 과거 자세로 정렬을 확정하지 않는다.
- 정렬 조건을 0.15초 유지해야 정렬 반응을 준다. 확인음은 포트 위치에서 재생한다.
- 손 관절로 플러그 끝을 추정한다. 실제 접촉과 삽입을 측정하지 않으므로 정렬 반응을 삽입 성공으로 표시하지 않는다.
- 전역 깊이 설정과 기존 PP_MR는 변경하지 않는다. 케이블의 실제 가시성은 XR-4에서 별도로 검증해야 한다.

## 깊이 가림의 제한

현재 플러그인이 노출하는 깊이 설정은 DepthTest, EnvironmentDepthEstimation, 카메라 기준 Near/Far 범위다. 포트별 깊이 오차 보정은 노출하지 않는다. 범위를 늘리는 것은 센서가 잘못 측정한 깊이를 고치는 기능이 아니다.

현장 관측: 손은 보이지만 케이블과 금속 플러그는 잘 보이지 않는다. 코드의 기본 깊이 적용 범위는 0–0.75m이며 실행 중 변경될 수 있다. 손이 범위 안에 있더라도 더 먼 플러그 끝/USB 포트가 범위 밖일 수 있으므로 실제 실행 값과 포트까지의 거리를 먼저 비교한다. `CXMR.DumpMRState`로 현재 요청된 깊이 설정을 기록할 수 있다. 범위에 포함되어도 사라진다면 케이블 자체의 깊이 인식과 표면 근처 깊이 오차를 분리해서 조사한다.

헤드셋에서는 콘솔에서 떨어진 손과 표면에 가까운 손을 비교하고, 손은 보이지만 케이블만 사라지는지도 구분해야 한다. 실물 플러그 끝과 추정 플러그 끝, USB 중심/삽입 축의 정합도 함께 확인한다. 센서 깊이와 가상 표면이 일치하지 않으면 피드백 개선만으로 사실적인 삽입 가림을 해결할 수 없다.
