# CXMR 통합 제어 창 설계

사용자가 승인한 구성: 하나의 CXMR Control 창, 사용/설정 모드, 좌측 차량·시점·보정·화면·USB 메뉴, 시작→정렬 확인→저장 보정 안내.

언어: UI와 에디터 툴팁은 영어. 코드 주석은 짧은 한국어로 작성함.

- UCXMRTuningWindowComponent가 하나의 데스크톱 창을 소유한다. UCXMRDesktopPanelComponent와 두 에디터 열기 버튼은 같은 창으로 연결한다. 기존 컴포넌트/콘솔 API는 유지한다.
- 사용 모드는 차량·시점·보정만 표시한다. 설정 모드는 화면/깊이, USB/손, 진단을 추가한다. 화면 전환과 모드 전환은 실제 차량이나 깊이 값을 바꾸지 않는다.
- 상단에 현재 차량, MR 상태, 보정 상태를 항상 표시한다. 보정 화면에서는 실제 bCalibrated 상태를 기준으로 확인 버튼을 활성화한다. 저장 결과는 파일 쓰기 성공 여부로 표시한다.
- 미세조정, 직접 배치, 보정 취소/다시 시작은 기존 기능에 연결한다. Learn은 저장까지 수행하는 고급 작업이므로 접힌 상세 설정 안에 둔다.
- 숫자는 슬라이더와 직접 입력, 선택은 목록, 설정은 도움말과 기본값 복구로 조작한다. 일반 설정의 기존 자동 저장 동작은 유지하고 보정의 명시적 저장과 구분한다.
- 손목 패널은 기존 간단한 조작을 유지한다. 데스크톱만 통합한다. 창을 닫아도 에디터 툴바에서 다시 열 수 있어야 한다.
- 현재 버그/USB 수정과 로컬 변경을 보존한다. 새 창의 조작은 빌드와 자동화 검사, 가능한 경우 렌더 가능한 실행으로 검증한다. 헤드셋 UX 평가는 별도다.

참고: https://developer.varjo.com/lab-tools 의 Edit/Use 모드, 도구별 그룹, 도움말 구성을 참고한다. Varjo Lab Tools의 기능 전체를 복제하는 작업은 아니다.
